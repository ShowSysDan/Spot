A show is a named time range — a performance, rehearsal or event — and the monitors that matter for it. Each one gets min / max / average (plus Leq, L10 and L90 for dB monitors) and a PDF report, which can be e-mailed or sent to another system automatically once the show ends. 321Theater can create shows through the API.
